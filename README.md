# Ultimate Video Editor — C++ / Qt6 / OpenGL / FFmpeg

    chmod +x start.sh && ./start.sh

Клавиши: Space — play/pause · C — ножницы (клик по таймлайну = разрез там, где курсор; Esc — выключить) · S — split на плейхеде ·
M — маркер · , / . — кадр назад/вперёд · Delete / Shift+Delete — удалить / ripple · Ctrl+колесо — масштаб таймлайна.
Красную линию таймлайна можно тянуть мышью (в любом месте), ползунок под плеером тоже перематывает.
Края клипов тянутся (trim). Меню «Вид» включает/выключает все окна; «Ассеты» = вкладки Медиа / Анимации / Шейдеры.
Плеер: ЛКМ-drag — двигать объект, колесо — масштаб, Shift+колесо — поворот, кнопка ● — запись движения в ключевые кадры.

## Новое
- ПКМ по таймлайну: добавить дорожку (видео/аудио — выбор в окошке), записать голос, текст, копировать/вставить, убрать эффект/анимацию, удалить дорожку.
- Запись голоса: ПКМ по аудиодорожке → «Записать голос» → у дорожки появляется красная кнопка и ползунок громкости записи.
  Микрофон выбирается в Файл → Настройки. Красная кнопка: 3-2-1 на видео, затем идёт видео и пишется микрофон. Стоп — кнопка / Space / Esc.
- Белые кружки на клипе — затухание в начале и конце (видео и звук). Голубые — длительность анимаций входа/выхода.
- Плашки эффектов и анимаций на клипе, ✕ убирает.
- Горячие клавиши: F1.

## Версия 3
- Все панели (и плеер) — стыкуемые окна: тащи за заголовок, бросай к любой стороне, ставь вкладками, «Вид → Раскладки окон».
- Эффект/анимацию можно перетащить из «Ассетов» прямо на клип (на таймлайне) или на кадр в плеере.
- Звук: собственный движок, звуковая студия канала (Микшер → FX ▸): EQ с графиком, компрессор, лимитер, гейт, реверб, дилей, хорус…
- Старт: окно с Image/Baner и Image/BanrIcon, недавние и найденные проекты. Формат проекта .uvmvideos.
- Запись: голос (ПКМ по аудиодорожке) и экран (меню «Запись»).
- AppImage: ./packaging/make-appimage.sh (один раз), дальше UltimateEditor-x86_64.AppImage запускается двойным кликом и показывает установщик.

## Если что-то не так
- Окна не двигаются мышью (Wayland):  UVE_X11=1 ./start.sh   — а ещё есть «Вид → Расположить окно» (без перетаскивания).
- Глючит звук:  UVE_NO_AUDIO=1 ./start.sh
- Раскладка сломалась: «Вид → Раскладки окон → Сбросить по умолчанию».
